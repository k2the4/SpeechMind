# SpeechMind text-emotion data plan

## Fixed output taxonomy

The model remains tied to SpeechMind's existing seven categories:
`joy`, `sadness`, `anger`, `fear`, `surprise`, `disgust`, and `neutral`.
The training formulation is multi-label for the six non-neutral categories. Neutral is derived only when no emotion label crosses the model's decision threshold. No new emotion category is introduced.

## Initial licensed data sources

### BRIGHTER Hindi

Source: https://huggingface.co/datasets/brighter-dataset/BRIGHTER-emotion-categories
Paper: https://aclanthology.org/2025.semeval-1.14/ (BRIGHTER dataset paper)
License declared by the dataset repository: CC BY 4.0.

The Hindi configuration contains the six non-neutral emotions used by SpeechMind: anger, disgust, fear, joy, sadness, and surprise. It is multi-label: an example can carry more than one label, and no selected emotion represents neutral. The paper reports that Hindi sentences were generated by fluent annotators around topics and then labelled by multiple Hindi speakers; a smaller number of quality-approved ChatGPT-generated examples are also included. This is useful human-annotated Hindi evidence, but it is not spontaneous conversational Hinglish.

The current Hugging Face repository metadata reports 2,556 train, 200 dev, and 2,020 test records for the `hin` configuration. The BRIGHTER paper's table reports different counts (2,841 / 108 / 1,070). The preparation script records the actual counts returned by the pinned Hugging Face snapshot and never substitutes paper counts for downloaded counts. Treat this as a dataset-version discrepancy to preserve, not silently reconcile.

### HinEmo (Hinglish)

Source: https://huggingface.co/datasets/theanonymous524/hinemo
License declared by its Hugging Face dataset card: CC BY 4.0.

The card reports 46,174 Hindi-English code-mixed comments split into train, validation, and test CSVs. It provides four labels: anger, joy, sadness, and disgust. Its label field is `gpt_emotion`; the card has no peer-reviewed citation yet and the labels are model-generated. The training adapter therefore marks this source as lower-confidence, weights it at 0.35, and supervises only those four known categories. It does not mark fear, surprise, or neutral as negative when the source does not label them.

### Sources not merged into this first checkpoint

- HinEmo-9 includes a valuable human-gold subset and Hindi/Hinglish/English varieties, but its nine-way taxonomy does not match SpeechMind's fixed seven categories (it lacks disgust and adds Love, Nostalgia, and Devotion). Its card also says CC BY 4.0 covers annotations/curation, not the underlying third-party YouTube comment text, and explicitly excludes deployments where an error could affect a person without human review. It is not used for this checkpoint.
- The SemEval-2024 EDiReF/MaSaC Hinglish corpus has seven SpeechMind-compatible labels plus Contempt and is context-rich conversational material. The accessible GitHub data repository has no explicit license file. It is not copied into training until the organizer's data-use permission is confirmed.
- IndieMH is a gated, non-commercial mental-health counselling corpus with a different multi-label taxonomy and explicit restrictions against clinical, diagnostic, or therapeutic use. It is not used for SpeechMind.

## Training and evaluation policy

1. Keep all original source splits; do not randomly repartition across the released train/dev/test sets.
2. Train a six-output multi-label MuRIL head. The loss uses a per-label mask so the four-label Hinglish source does not fabricate fear, surprise, or neutral negatives.
3. Use BRIGHTER Hindi dev for model selection and BRIGHTER Hindi test for held-out Hindi evaluation. Report HinEmo validation/test metrics separately and clearly label them as GPT-label evaluation, not human gold.
4. Report per-emotion precision/recall/F1, macro/micro F1, and the derived-neutral result. Preserve source, split, label provenance, and source weight in every prepared record.
5. Only the Hindi/Hinglish text branch is enabled by this checkpoint. English continues to use the existing English-only fallback. The model is experimental and must not be presented as clinically or psychologically valid.
